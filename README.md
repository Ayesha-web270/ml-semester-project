# Sleep Health & Lifestyle — ML Semester Project

A complete end-to-end Machine Learning pipeline to predict **Sleep Disorders** 
(None / Insomnia / Sleep Apnea) based on lifestyle and health indicators.

---

##  Description

This project is a complete Machine Learning pipeline built on the Sleep Health 
and Lifestyle Dataset. The goal is to predict whether a person suffers from a 
Sleep Disorder based on daily habits like sleep duration, stress level, physical 
activity, BMI, and more. The project covers all major steps of a real-world ML 
workflow — from raw data exploration to a trained classification model.
